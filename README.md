# 星轨疾跑 · Star Rail Runner

为 XBuilder 制作的原创横版无尽跑酷游戏，参考《天天酷跑》的自动前进、跳跃避障和金币收集玩法。角色、场景、界面和音效均为本项目原创生成素材。

## 文件

- `StarRailRunner.xbp`：直接导入 XBuilder 的项目文件，无需解压。
- `source/`：完整可编辑源码，含舞台和角色 `.spx` 脚本、PNG 素材、JSON 配置、WAV 音效、生成工具和测试。
- `preview.png`：首页美术预览。
- `gameplay.png`：由项目实际美术素材合成的游戏画面示意。
- `验证报告.md`：验证范围与结果。
- `import-layout.png`：根据最终导入文件中的实际初始配置，在固定 480 × 360 视口中合成的布局验证图。

## 导入

1. 打开 https://x.qiniu.com ，按网站提示登录，创建或进入一个你自己的项目。
2. 在编辑器左上角的项目菜单中，选择 **导入项目文件…**。
3. 选择 `StarRailRunner.xbp`。这是完整项目，建议导入到一个空白项目中。
4. 点击编辑器的运行按钮，在游戏首页点击 **即刻出发** 或按 Enter。
5. 如果键盘无响应，先点击游戏画面，再使用按键。

本次修正版使用 XBuilder 固定的 480 × 360 视口，所有角色尺寸和运动坐标均已同步适配。编辑器会忽略自定义运行尺寸，因此不能只修改 run 字段。

项目采用原生 spx 脚本和标准 `.xbp` ZIP 目录结构。目标接口为 XBuilder / spx 3.3.0；不同在线版本的菜单位置可能略有变化。

## 操作

| 操作 | 键盘 | 画面按钮 |
|---|---|---|
| 开始 / 结算后重开 | Enter | 即刻出发 / 再跑一次 |
| 跳跃 | Space / ↑ / W | 跳跃 |
| 二段跳 | 空中松开后再按跳跃 | 空中再点跳跃 |
| 下滑 | ↓ / S | 下滑 |
| 快速落地 | 空中按 ↓ / S | 空中点下滑 |
| 暂停 / 继续 | P / Esc；暂停时也可 Enter | 右上暂停 / 继续奔跑 |
| 音效开关 | M | 声音 ON / OFF |

按住跳跃不会自动消耗二段跳。下滑持续 0.8 秒。触屏设备可点击画面按钮，推荐横屏运行。

## 规则

- 自动前进，初始速度 300 像素/秒，逐步提升到 480 像素/秒。
- 得分 = 向下取整的距离（米）× 10 + 金币数 × 50。
- 低箱需要跳跃；高墙推荐二段跳；飞行器可以下滑躲避；断桥需要跳过去。
- 前 20 秒先出现低箱和飞行器，之后开放高墙与断桥。
- 初始 3 格能量。碰撞消耗 1 格，之后有 1.8 秒保护时间。
- 掉入断桥会消耗 1 格能量，并救回跑道；护盾也能抵挡这次伤害。
- 护盾持续 9 秒，可抵挡一次伤害。磁力持续 9 秒，可吸取附近金币。
- 能量耗尽后进入结算，可立即重开。
- 最佳分在本次游戏运行会话内保留；停止运行或刷新后重新计算。

## 修改源码

`source/main.spx` 包含玩法规则、参数、输入和主循环；每个角色都有同名 `.spx` 脚本。例如：

- `Runner.spx`：奔跑、跳跃、下滑动画和受伤闪烁。
- `Obstacle0.spx` ～ `Obstacle3.spx`：障碍物显示。
- `Coin00.spx` ～ `Coin23.spx`：金币对象池显示。
- `City*.spx`、`Track*.spx`：两层视差滚动。
- `StartButton.spx`、`JumpButton.spx` 等：按钮事件。
- `assets/index.json`：480 × 360 原生舞台（960 × 540 设计坐标统一按 0.5 倍渲染）、图层顺序及背景。
- `assets/sprites/`：角色造型与角色配置。
- `assets/sounds/`：原创合成音效。

建议直接导入 `.xbp` 后在 XBuilder 中修改并导出，这样不需要安装本地工具。

## 显示适配回归检查

```sh
python3 source/tools/verify_layout.py
```

该工具读取真实 `.xbp` 中的尺寸、锚点、位置和缩放，核对关键界面边界，并生成 `import-layout.png`。

## 本地重新生成

已附齐素材，导入和运行游戏不需要 Python 或 Go。以下工具仅供开发者修改后重建、复核。

需要 Python 3.10+ 和 Pillow：

```sh
python3 -m pip install Pillow
python3 source/tools/build.py
```

脚本会重新生成原创素材、角色脚本、配置及同目录的 `.xbp`。修改界面/角色逻辑时应修改 `tools/build.py`，避免生成时覆盖对应角色脚本；舞台规则 `main.spx` 会保留。中文重建需要支持中文的本地字体，可通过 `RUNNER_FONT` 指定字体路径；macOS 默认使用 Arial Unicode。

只想重新打包已修改的脚本和素材，不重新生成美术与角色脚本：

```sh
python3 source/tools/package.py
```

运行 19 项逻辑测试（需 Go 1.22+）：

```sh
python3 source/tools/test_core.py
```

使用官方 spx 解释器直接检查最终 `.xbp` 中的脚本和资源（需 Go 1.26+，首次需要下载 Go 模块）：

```sh
cd source/tools/native-check
go mod tidy
go run . ../../../StarRailRunner.xbp
```
